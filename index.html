Engineered for Scale

Why Doclify Outperforms Generic Prompts

🧬

Subagent Context Isolation

Every file is processed in an ephemeral, bounded context window. Raw token noise and syntax boilerplate never enter the global synthesis window.

⚡

Groq LPU Acceleration

Runs blazingly fast inference on Groq hardware (Llama 3.3, Qwen 32B), generating complete repository docs in seconds instead of minutes.

💾

Incremental Cache

State is persisted in .doclify/cache.json. When you modify a file, run doclify update <path> to re-summarize only the diff.

Research Backed

The ACE (Advanced Context Engineering) Pipeline

1 Frequent Intentional Compaction (FIC)

Keeps context utilization in the optimal 40–60% zone. A 500-line source file is compacted into 3–4 dense, structured sentences before entering synthesis.

2 Research → Plan → Implement Separation

doclify init is pure discovery (manifest generation). doclify run compiles summaries into final documentation. Concerns never bleed across stages.

3 Prompts as Versioned Source Assets

Prompt templates (batch_summary.txt & final_summary.txt) are treated as first-class engineering artifacts with strict formatting boundaries and negative constraints.

Pipeline Dataflow:
[Source Files] ─── scanner ───▶ [doclify.yaml]
[Raw Code (100k+ tokens)] ─── subagents ─▶ [cache.json (5k tokens)]
[cache.json summaries] ─── synthesis ─▶ [README.md Output]
Result: 95% token noise reduction, zero hallucinated methods, and crystal-clear architectural narrative.

Getting Started

Setup in 3 Commands

1. Install Doclify pip / uv
git clone https://github.com/hardikkaurani/Doclify.git
cd Doclify && pip install -e .
2. Set Your Groq API Key console.groq.com
export GROQ_API_KEY="your_api_key_here"
# or on Windows PowerShell: $env:GROQ_API_KEY="your_api_key_here"
3. Generate Documentation run & done
doclify init && doclify run

Command Reference

Doclify CLI Commands

doclify init

Discovers project files respecting .gitignore and creates doclify.yaml context manifest.

doclify models

Displays real-time interactive table of all available Groq models with context limits and developers.

doclify set default <model>

Configures default model in doclify.yaml (e.g. llama-3.3-70b-versatile).

doclify update <path>

Re-runs compaction only for the target file, or pass . to immediately rebuild docs from cache.
